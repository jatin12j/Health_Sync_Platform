# 🏥 Health Sync Platform

A modern **Healthcare & Biomedical Devices Management System** developed using **PHP, MySQL, JavaScript, Bootstrap, HTML, and CSS**. The platform streamlines healthcare management by providing modules for appointment booking, medication management, health records tracking, authentication, and patient monitoring through a clean and responsive web interface.

---

## 🚀 Project Overview

Health Sync Platform is designed to simplify digital healthcare operations by combining patient management, health tracking, and medication services into one centralized system.

The system allows users to:

* Register and securely log in
* Book and manage appointments
* Track personal health metrics
* Manage medication orders
* Access healthcare dashboards
* Maintain electronic health records

This project focuses on **backend development, database management, CRUD operations, authentication, and server-side processing** while also delivering a responsive frontend experience.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Health_Sync_Platform.git
```

## 2️⃣ Move Project to XAMPP htdocs

```bash
C:/xampp/htdocs/
```

## 3️⃣ Start Apache & MySQL

Open **XAMPP Control Panel** and start:

* Apache
* MySQL

## 4️⃣ Create Database

* Open phpMyAdmin
* Create a database
* Import SQL file (if available)

## 5️⃣ Configure Database Connection

Update database credentials inside:

```php
db.php
```

Example:

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "health_sync";
```

## 6️⃣ Run the Project

Open browser:

```bash
http://localhost/Health_Sync_Platform/
```
